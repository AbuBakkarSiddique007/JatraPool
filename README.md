# JatraPool

> **Share a seat. Split the fare. Survive Dhaka traffic.**

A ride-pooling platform engineered specifically for Dhaka rush-hour traffic, featuring atomic seat allocation, integer poysha arithmetic, and transparent route pooling.

---

## 1. Tech Stack
* **Frontend**: Next.js 14+ (App Router), Tailwind CSS, Leaflet.js (OpenStreetMap)
* **Backend**: Node.js + Express.js (TypeScript modular monolith)
* **Database**: PostgreSQL with Prisma ORM
* **Validation & Auth**: Zod schema validation, JWT auth with 1-click persona switcher
* **Orchestration**: Docker Compose with healthchecks
